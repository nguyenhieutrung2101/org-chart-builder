# Function Inventory — Org Builder

> Generated by full read of the codebase at commit `fe0ad60` (v9).
> Scope: all source files; `node_modules`, build output, tests and vendored code excluded (none exist in this repo).

## Source files & roles

| File | Lines | Role |
|---|---|---|
| `public/index.html` | 3101 | **The entire application** — single-file app: CSS (l.7–338), HTML (l.340–574), JS (l.576–3099). Served as-is by Cloudflare Workers static assets. |
| `wrangler.jsonc` | ~10 | Cloudflare Workers config (`assets: ./public`). No code. |
| `README.md` | ~70 | Documentation. No code. |

All functions below live in **`public/index.html`**. There is no module system — every top-level `function` is a global. **[PUBLIC]** marks functions that are UI entry points (wired to a DOM event / called from generated DOM) or cross-section APIs; everything else is internal helper.

Conventions used below:
- Types are inferred (the code is untyped ES5-style JS). `NodeId` = string like `n1`; `VNodeId` = `v1`; `Node`/`VNode` = the plain objects stored in `nodes`/`vnodes` Maps; `Layout` = return value of `layout()`.
- "state" = the global mutable state (`nodes`, `rootIds`, `sel`, `focusId`, `fcGroups`, `fcs`, `roleBoxes`, `ruleGrids`, `vlineGrids`, `ruleMode`, `vnodes`, `vroots`, `cigs`, `zoom`, …).
- Side-effect legend: **DOM** (writes DOM), **state** (mutates globals), **undo** (pushes undo snapshot via `snap`), **LS** (localStorage), **DL** (triggers file download), **CB** (clipboard).

## Notes, dead code & latent issues (observed during read)

1. **Dead: `applyZoom` (l.2750).** After the smooth-zoom refactor, wheel and all three zoom buttons route through `animateZoomTo`, and `fitZoom` has its own body. No remaining caller inside the app. Safe to delete (it is only exercised by external test scripts).
2. **Latent bug: `copyText` (l.1459) parameter `t` shadows the i18n function `t()`.** In the fallback error path, `msg(t('msgCopyBlocked'))` would attempt to call the *string being copied* as a function and throw. Only reachable when both the async Clipboard API and `execCommand('copy')` fail — rare, but the toast would never show. Rename the parameter to fix.
3. **Dead i18n key: `cbqlnsFull`** (defined in both locales, l.645/767) — no `t('cbqlnsFull')` call site anywhere.
4. **Stale comments:** the JS table of contents (l.579) still says “ORG BUILDER v5” and doesn’t list sections [7v]/[8f]/i18n; `cbqlnsOf`’s comment (l.2242) still mentions the removed “ngoài SĐTC (id dạng x*)” feature; `seedRules`’ leading comment (l.971) says “theo ma trận chuẩn” though it now seeds nothing.
5. **Un-i18n’d literals:** the `Focus:` label in `#focusChip` (l.389) and the `Fund Center` card header (l.533) are hard-coded (every other static label uses `data-i18n`).
6. `debounce` has exactly one consumer (`refreshFlowResultSoon`) — fine, just noting fan-in.

*Every entry above was verified against the actual source during a full read (lines 1–3102). Nothing is inferred from memory of earlier revisions.*
