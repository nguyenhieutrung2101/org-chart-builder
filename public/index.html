About this project

Org Builder · project affogato

A small tool for one recurring job: draw a company's org tree once, then use it twice — as a printable organisation chart that goes into an official document, and as the source that decides who reviews and approves each budget request.

What it believes in

  • Local-first. No back-end, no account. Your data is one JSON file that you own, save and reopen.
  • One source of truth. One org tree feeds both modules; change a box once and it changes everywhere.
  • What you see is what prints. The page is laid out in millimetres, so the screen, the printout and the PDF match.
  • Hand-built and plain. Static HTML + vanilla JavaScript, no framework, no build step, every feature covered by browser tests.

About me

I'm Trung. I built Org Builder for the budget-approval work I deal with every day, starting from a simple frustration: the org chart already knows who approves what, so nobody should have to retype it into a matrix. "Affogato" is the espresso-over-gelato that fuelled most of the commits.
